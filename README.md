## 🌐 Deploying to GitHub Pages

This repository is structured to run both as a local server (with Python API) and as a static website on **GitHub Pages**:

1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/ (root)`.
4. Click **Save**. Your site will be published at `https://samrat-bhosale.github.io/Crappy-charts/`.
